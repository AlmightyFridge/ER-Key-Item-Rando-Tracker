# Elden Ring Key Item Randomizer for Manual Archipelago PopTracker Pack

This PopTracker pack is to be used with the "Elden Ring Key Item Randomizer for Manual Archipelago" found here: https://github.com/AlmightyFridge/AP-Manual-ER-Key-Item-Rando <br />
<br />
Recommended PopTracker version 0.35.2 or later. Older versions may have compatibility issues. <br />
<br />

## Features

- Archipelago autotracking
- Archipelago check sending. **Can be used as an alternative to the Manual Client!**
- Massive **zoom-able** maps of the overworld, underworld, and DLC
- Tabs for both combined regional locations (Condensed) and every single check accurately placed on the map (Detailed)
- Automatic layout switching when settings are changed
